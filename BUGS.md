# Bugs

Known defects, worst first. Each entry says what you see, what should happen,
and where the code lives. Delete an entry when it is fixed — the git history
keeps the record.

- By default a machine does not attach to its public IP.
- Moving a terminal sometimes snaps it back to its original position shortly
  after the drag starts.
- Scrolling with the mouse does not work with a remote terminal.
- Remote agents do not paste large instructions correctly.
- Running a Claude agent in Termscape does not include the user's MCPs.
